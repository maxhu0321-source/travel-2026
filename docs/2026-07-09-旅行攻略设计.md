# 旅行攻略HTML设计文档

## 项目概述
制作一个移动端优先的旅行攻略HTML，包含两段独立旅行：
- 东北段：2026-07-10 至 2026-07-18（9天）
- 成都九寨沟段：2026-07-21 至 2026-07-25（5天）

## 技术栈
- 单文件HTML（内嵌CSS+JS）
- 无外部依赖
- localStorage保存checklist状态

## 配色方案（东北特色）
- 冰雪蓝 `#5B9BD5`（主色）
- 暖橙 `#E67E22`（点缀）
- 森林绿 `#2E7D32`（自然）
- 浅灰背景 `#F5F7FA`
- 卡片白 `#FFFFFF`

## 整体结构
- 单个HTML文件
- 顶部两个tab：东北段 / 成都九寨沟段
- 每个tab独立完整呈现

## 核心模块

### 1. Hero区域
- 标题：旅行名称（东北之旅 / 成都九寨沟之旅）
- 副标题：日期范围 + 主要城市
- 背景色：冰雪蓝渐变

### 2. Sticky Tabs
- 概览 / 行程 / 贴士
- 滚动时固定在顶部

### 3. 概览卡片
- 天气卡片：各城市天气预报
- 花费预估：交通+餐饮+门票
- 重要提示：天气风险、注意事项

### 4. 行程时间线
- 按日期分组
- 每时段显示：时间 + 地点 + 活动 + 交通方式
- 已完成/待完成状态标识

### 5. 贴士Checklist
- 带localStorage状态的待办清单
- 点击勾选，刷新页面保持状态

### 6. JS功能
- Tab切换
- 复制地址
- Checklist状态保存
- Toast提示
